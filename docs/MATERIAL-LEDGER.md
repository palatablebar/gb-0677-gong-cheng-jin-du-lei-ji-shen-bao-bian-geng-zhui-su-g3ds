# 甲供钢材跨期领用退库承接规则

面向甲供钢材的领用（issue）、耗用（consume）、退库（return）、余料（surplus）四类事件，
解决记录分散、累计领用量直接抵扣导致历史签证被重算、同一材料重复扣的问题。

## 核心口径

每个材料（按规范材料码归一，别名如「螺纹钢 / HRB400 / HRB400 螺纹钢」视为同一材料）
维护一个跨期滚动的「未结清新增材料池」，逐期承接，绝不回改历史签证。

单周期固定处理次序（可重放、可复核）：

1. **领用入池**：本期领用量加入未结池。
2. **退库冲减**：退库先冲本材料未结池；
   - 未结池足够：`退库承接冲减量 = 退库量`，当期净额即被冲减；
   - 退库超过未结池：超额部分计入「退库待结转」，在以后期间继续冲减，
     **不产生负抵扣、不回改旧签证**。
3. **耗用校验与出池**：耗用必须有未结池作为领用依据，否则整事件隔离
   （CONSUME_EXCEEDS_LEDGER）；通过后耗用从未结池出池。
4. **余料登记**：余料仍属未结池，只登记数量、不改变余额、不提前抵扣。

### 三个可签认结果

- **本期耗用** = 本期耗用量 × 单价，是财务/审计核对的耗用口径。
- **本期抵扣** = min(本期耗用量, 期初未结 + 本期领用 − 本期退库冲减) × 单价。
  两道约束同时生效：抵扣不超过本期耗用（未耗用余料不得提前抵扣），
  也不超过耗用后未结清新增材料款。
- **退库承接** = 本期退库冲池金额 + 前期「退库待结转」在本期实际承接冲减金额；
  期末仍待结转的退库款单列，结转下期。
- **剩余可扣** = 期末未结清新增量 × 单价，结转下期继续抵扣。

### 跨期承接示例（仓内样例）

Q235 圆钢 2026-12 退库 40t，而当期未结池仅 30t：30t（117,000 元）当期冲减净额，
超额 10t（39,000 元）挂退库待结转；2027-01 该材料新领用 15t 入池后，
待结转的 39,000 元在本期承接冲减，待结转清零。全过程 2026-12 及更早签证金额不变。

## 历史签证不变与幂等

- 签证一经「已签认」，对应周期关闭：之后补录该周期事件一律 PERIOD_CLOSED 隔离，
  不落库、不重算，签证快照 sha256 摘要保持不变。
- 事件以 `event_id` 为业务幂等键，库内主键唯一：同一领用或退库重试只计
  `duplicate_skipped`，不产生第二次抵扣。
- 签证发布在单事务内完成重算、快照写入、版本更新；任何一步失败整体回滚，旧版保留。
- 同内容重复发布幂等返回原签证（不新增版本）；内容变化但 `base_version` 陈旧返回 409。
- 被拒事件（字段非法、关闭期、无领用依据耗用、同周期单价冲突）只进隔离区，不落权威台账。

## 金额与精度

Decimal 参与全部数量金额计算，金额按分（0.01）四舍五入量化后序列化为字符串；
业务编号全程按文本保形；时间必须带 UTC/固定偏移，先归一到 UTC。
